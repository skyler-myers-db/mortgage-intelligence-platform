# Enterprise readiness checklist

- [ ] Unity Catalog table permissions documented.
- [ ] Genie scoped only to curated metric views/gold tables.
- [ ] Lakebase audit schema deployed.
- [ ] App resource permissions least privilege.
- [ ] Bundle validates for dev and prod.
- [ ] No secrets in repository.
- [ ] Synthetic PII confirmed.
- [ ] Evidence ids trace to source tables.
- [ ] Approval gate cannot be bypassed in UI.
- [ ] API validates input and avoids raw SQL injection.
- [ ] Frontend build and backend tests pass in CI.
- [ ] Fallback path documented.
